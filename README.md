# Aschenmond

Ein kurzes Gothic-Actionspiel aus der Vogelperspektive – schnelle Hiebe, Ausweichrollen, Ausdauer und Bosskämpfe.

## Spielen

`index.html` im Browser öffnen. Keine Installation, kein Server, keine Abhängigkeiten.

## Steuerung

| Aktion | Tastatur/Maus |
|---|---|
| Bewegen | WASD oder Pfeiltasten |
| Zielen | Maus |
| Hieb | Linksklick (oder J) |
| Ausweichen | Leertaste oder Rechtsklick |
| Bluttrank | E (oder Q) |
| Testmenü | T (auf dem Titelbildschirm) |
| Zurück zum Titel | Esc |

## Inhalt

Drei Nächte mit mehreren Gegnerwellen und je einem Bosskampf am Ende. In der dritten Nacht fällt eine Entscheidung, die das Ende beeinflusst.

<details>
<summary>Spoiler: Schauplätze und Bosse anzeigen</summary>

- **Nacht 1 – Die Aschengasse:** drei Wellen, Boss „Der Glockenwolf"
- **Nacht 2 – Die versunkene Kapelle:** zwei Wellen, Boss „Die Aschenäbtissin"
- **Nacht 3 – Der Knochenacker:** zwei Wellen, Boss „Der Pfandherr". Vor dem Tor bietet ein Namenloser seine Klinge an; nimmt man an, kämpft er im Bosskampf mit.

**Aschenopfer:** 500 Asche für +1 % Leben und Schaden oder 1000 Asche für +3 %.

**Bloodfrenzyattacke:** Nach sechs Treffern ohne Gegentreffer macht der nächste Treffer 50 % mehr Schaden.
